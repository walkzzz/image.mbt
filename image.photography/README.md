# walkzzz/image.photography

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的计算摄影子模块：HDR 处理、夜景增强、景深 / 虚化、多帧融合、全景拼接、超分辨率等。

## 安装

```bash
moon add walkzzz/image.photography@0.1.0
```

## 主入口

完整文档见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/walkzzz/image.mbt)。
