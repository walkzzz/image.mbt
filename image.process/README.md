# walkzzz/image.process

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的图像处理算法子模块（**90+ 子包**）：色彩转换 / CLAHE / Retinex / 去雾、边缘检测 / Canny / 霍夫、Harris / ORB / SIFT / 光流 / 模板匹配、FFT / DCT / 小波、分水岭 / SLIC / grabCut、Seam Carving、**OCR 全链路**（数字/英文/中文/表格/手写体/多语言混合，19 模块）等。

## 安装

```bash
moon add walkzzz/image.process@0.1.0
```

## 主入口

完整文档见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/walkzzz/image.mbt)。
