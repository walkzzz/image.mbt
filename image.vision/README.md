# walkzzz/image.vision

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的计算机视觉子模块：OCR、人脸识别、姿态估计、SLAM、视频处理、3D 视觉等。

## 安装

```bash
moon add walkzzz/image.vision@0.1.0
```

## 主入口

完整文档见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/toadium/image)。
