Live demo

在浏览器里直接跑

下面的 QR、滤镜与 PNG 摘要全部由同一份 MoonBit 编译产物在本地计算；页面不调用后端，也不请求第三方接口。

QR 生成

render_qr

输入文本 → 模块级 QR 图像 → PNG 编码；模块大小与静区可调。

点击「生成」…

QR + 滤镜

adjust_brightness · box_blur

先渲染 QR，再调整亮度并做方框模糊；输出仍是 PNG。

点击「处理」…

PNG 编解码摘要

get_image_summary

把上一张 PNG 的字节重新解码，输出格式、尺寸、通道与位深。

点击「解读当前 PNG」…

Get started

按模块接入

根模块只负责版本与文档；用户直接 import 子模块包，按需引入编解码或处理算法。

安装子模块
moon add walkzzz/image.core@0.1.0
moon add walkzzz/image.codec@0.1.0
moon add walkzzz/image.process@0.1.0
构建浏览器演示产物
moon build --target js --release playground
工程门禁
moon check --deny-warn --target all
moon test  --target all
node scripts/check_coverage.mjs coverage-summary.txt --min 80.5
node scripts/mutation_test.mjs --min-kill=80
node scripts/check_docs.mjs
node scripts/check_pages.mjs
解码任意格式
let bytes = @fs.read_file("photo.jpg")
let img = @lib.load_from_bytes_auto(bytes)
// img.width / img.height / img.channels
滤镜与几何变换
let bright = @color.adjust_brightness(img, 30)
let soft = @filter.box_blur(bright, 1)
let small = @transform.resize_f(@transform.resize(img, 320, 240), 320, 240)
编码 PNG
let png = @lib.encode_png(small)
@fs.write_file("out.png", png)

Under the hood

这是怎么在浏览器里跑的？

  1. 1

    playground/ 是根模块的 foreign_library 包，导出 QR 生成、滤镜与 PNG 摘要函数。

  2. 2

    moon build --target js --release playground 生成一份 JS；PNG 以十六进制字符串跨边界。

  3. 3

    页面把 hex 还原为 PNG Blob 显示；QR 渲染、亮度、模糊与解码全部在本地完成。

  4. 4

    CI 在四后端跑 6664 测试；check_pages.mjs 验证导出与语义，Pages 部署 docs/。
