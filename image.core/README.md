# walkzzz/image.core

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的核心类型子模块：`Image`（8 位）/ `Image16`（16 位）/ `ImageF`（HDR 浮点）/ `LoadError` / 安全算术（safe_math，`moon prove` 8 goals）。

## 安装

```bash
moon add walkzzz/image.core@0.1.0
```

## 主入口

完整文档、18 格式编解码、90+ 图像算法与 OCR 全链路见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/toadium/image)。
