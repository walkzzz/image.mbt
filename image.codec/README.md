# walkzzz/image.codec

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的格式编解码子模块：**18 种格式**（PNG / JPEG / BMP / GIF / QOI / TGA / PSD / HDR / PNM / TIFF / ICO / CUR / ICNS / APNG / WebP / AVIF / HEIF / JPEG-XL）+ 颜色空间 + 元数据（EXIF/IPTC/XMP）+ 条码（EAN-13/QR）。

## 安装

```bash
moon add walkzzz/image.codec@0.1.0
```

## 主入口

格式支持矩阵、统一 API（`save_image_auto` / `get_image_info_extended`）与完整文档见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/toadium/image)。
