# walkzzz/image.domain

[image](https://mooncakes.io/docs/walkzzz/image.mbt) 的行业领域子模块：医学影像、遥感、加密图像、数字水印、图像取证、质量评估等。

## 安装

```bash
moon add walkzzz/image.domain@0.1.0
```

## 主入口

完整文档见主模块 [walkzzz/image.mbt](https://mooncakes.io/docs/walkzzz/image.mbt) 与 [GitHub 仓库](https://github.com/walkzzz/image.mbt)。
